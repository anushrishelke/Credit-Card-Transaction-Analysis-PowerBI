# Credit Card Transaction & Financial Analysis Dashboard

## Project Overview
This project is an interactive Credit Card Transaction and Financial Analysis Dashboard developed using Microsoft Power BI.
The dashboard analyzes credit card transactions, revenue, interest, expenditure patterns, card categories and customer segments to generate meaningful business insights.

## Project Objectives
- Analyze credit card transaction data.
- Track revenue, transaction amount and interest.
- Understand customer spending patterns.
- Compare revenue across different card categories.
- Analyze transaction methods such as Swipe, Chip and Online.
- Explore customer segments based on job and education.
